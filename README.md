# Vortex Markets

Complete live trading broker website with:
- Admin dashboard (users, trades, transactions, KYC)
- Multi-user auth (register / login / logout)
- KYC verification flow
- Live TradingView charts + simulated trading
- 3D glassmorphism UI

## Quick start
Open index.html or deploy the folder to Netlify / GitHub Pages.
